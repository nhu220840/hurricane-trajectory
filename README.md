# Hurricane Trajectory Prediction

This project is a complete deep learning pipeline designed to predict the future trajectory of hurricanes. It uses historical storm track data from **IBTrACS** to train and compare two different **LSTM** (Long Short-Term Memory) models for time-series forecasting. The project also includes an interactive **Flask** web application to visualize model predictions and explore the historical data.

---

## Core Concept & Approach

The project frames hurricane trajectory prediction as a time-series forecasting problem.

1. **Problem**  
   Given a sequence of a hurricane’s past `N` observations (e.g., latitude, longitude, wind speed, pressure at 6-hour intervals), predict its change in position (**Δlatitude, Δlongitude**) for the next time step.

2. **Data**  
   The pipeline is designed to work with the **IBTrACS (International Best Track Archive for Climate Stewardship)** dataset. It first prepares this raw data, then processes it into fixed-length sequences (windows) for training.

3. **Modeling**  
   The project implements and compares two distinct LSTM models:
   - **PyTorch LSTM (`LSTMForecaster`)** — a standard, optimized LSTM model built using PyTorch’s `nn.LSTM` module.  
   - **Scratch LSTM (`LSTMFromScratchForecaster`)** — a complete LSTM model built “from scratch” using manually defined `_ManualLSTMCell` logic to demonstrate the underlying mechanics.

4. **Demonstration**  
   A Flask web application (`web_app/app.py`) provides an interactive interface to:
   - **Compare Predictions:** Select a random storm from the test set and visualize the historical track, the true future path, and the predictions from both the PyTorch and Scratch models.  
   - **Explore Data:** Display all historical storm tracks from the raw dataset on an interactive map.

## Getting Started

### Prerequisites

- Python **3.8+**
- The raw IBTrACS data file (e.g., `ibtracs.last3years.list.v04r01.csv`) placed in the `data/raw/` directory.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/nhu220840/hurricane-trajectory.git
   cd hurricane-trajectory
   ```

2. **Create and activate a virtual environment (recommended)**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

## How to Run the Project

There are two main parts to this project: the **Pipeline** (for generating models) and the **Web Application** (for visualizing results).

### 1) Run the Pipeline

You must run the pipeline first to process the data and train the models. The `main.py` script is the entry point for all pipeline steps.

**Easiest method (run all steps):**
```bash
python main.py --all
```

**Run steps individually:**
```bash
# Step 1: Clean the raw IBTrACS CSV
python main.py --prepare-raw-data

# Step 2: Create processed .npz file and scalers
python main.py --process-data

# Step 3: Train the models (options: 'all', 'pytorch', 'scratch')
python main.py --train all

# Step 4: Evaluate the trained models
python main.py --evaluate
```

After running the pipeline, `data/processed/` will contain the `.npz` data and `.pkl` scalers, and `models/` will contain the checkpoints:
- `best_lstm_pytorch.pt`
- `best_lstm_scratch.pt`

### 2) Run the Web Application

Once the artifacts (models, scalers, and processed data) have been generated by the pipeline, you can start the interactive web demo.

1. **Start the Flask app**
   ```bash
   python web_app/app.py
   ```

2. **Open your browser** and navigate to:  
   <http://127.0.0.1:5000>

The application will load the models and data into memory, allowing you to fetch test samples, see predictions, and view the **All Tracks** map.
